# Журнал изменений

Здесь перечислены изменения для пользователей. Раздел «Готовится» относится к исходникам и тестовым сборкам, а не к последнему опубликованному установщику.

## Готовится

### Добавлено

- Поиск песни по фрагменту текста через Genius с подбором доступного трека в Яндекс Музыке.
- Варианты запроса с транслитом, другой раскладкой и близким написанием; похожие запросы и объединение результатов без дублей.
- Караоке по словам и отсчёт перед первой строкой, если у неё есть тайминг и вступление длится не меньше трёх секунд.
- Управление воспроизведением через Media Session: сведения о треке и медиакнопки системы.
- Настройка «Не воспроизводить AI-треки» с проверкой по данным Slopless.
- Матовая тема с графитовыми поверхностями и тёплым акцентом.
- GitHub Actions для Windows MSI, Windows ZIP без установки, Linux DEB и AppImage; SHA256 для пакетов.

### Исправлено

- Очередь больше не перекрывает текст в небольшом окне. При закрытии не остаётся исчезающей панели, которая ломала сетку и уменьшала обложку.
- Вид текста учитывает фактическое разворачивание окна, в том числе через системные кнопки.
- Переходы между строками используют одну плавную прокрутку. После ручного скролла автопрокрутка ненадолго приостанавливается.
- Устаревший ответ источника текста или поиска не подменяет более свежий результат.
- Отсутствие текста не закрывает окно с плеером и очередью.
- Отмена редактирования плеера не откатывает выбранную тему. Повреждённое отдельное поле настроек не сбрасывает всё оформление.
- При восстановлении длинной перемешанной очереди сохраняются текущий трек и исходный порядок сохранённой части.
- Фильтр AI-треков проверяет песню до запроса аудио; очередь из одних отфильтрованных треков не зацикливается.
- Обновлён npm lock-файл: зависимости устанавливаются с нуля через `npm ci`.

### Изменено

- Убраны декоративные точки визуализатора, метки и тайминги возле строк текста, видимые полосы прокрутки. Прокрутка колёсиком и тачпадом сохранена.
- Убрана повторная анимация появления слов при смене строки.
- README, инструкции по сборке и формы для сообщений об ошибках обновлены.

### Что пока зависит от источников и платформы

- При таймингах только для строк подсветка отдельных слов приблизительная. Без таймингов автоматического караоке нет.
- Поиск по тексту может найти песню, которой нет в доступном каталоге Яндекса. В таком случае результат показывается без воспроизведения.
- Linux-пакеты требуют проверки воспроизведения, трея и медиаконтролей на реальной системе. Успешная сборка не заменяет эту проверку.

## [1.0.0] — 27 сентября 2026

Первый публичный релиз Aureon для Windows x64.

- Установщик MSI на русском языке.
- «Моя волна», плейлисты, любимые треки и поиск.
- Окно текста песни и очередь воспроизведения.
- Настройки фона и цветов, мини-плеер, эквалайзер, горячие клавиши и Discord-статус.
