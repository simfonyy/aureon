# Изменения в Aureon

Для бага открой Issue и опиши, как его повторить. Для новой функции сначала объясни сценарий: что хочешь сделать и что сейчас мешает.

## Работа с кодом

1. Создай ветку от `main`.
2. Установи зависимости через `npm ci` и запусти `npm run tauri:dev`.
3. Сделай изменение в рамках одной задачи. Сохрани существующее оформление, если задача не касается дизайна.
4. Запусти `npm test` и `npm run build`. При изменении Rust — `cargo test --locked --lib --manifest-path src-tauri/Cargo.toml`.
5. В pull request напиши, что изменилось, как это проверить и на какой системе проверялось.

Требования к сборке: [DISTRIBUTION.md](docs/DISTRIBUTION.md).

Если изменение заметно пользователю, добавь пункт в раздел готовящегося выпуска в [CHANGELOG.md](CHANGELOG.md). Не отмечай функцию как выпущенную до публикации релиза.

Не добавляй в репозиторий `.env`, токены, cookies, личные данные и готовые бинарники. Сборки передаются через Actions или Releases.
